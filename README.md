# Towns

A minimalist city builder with a deep traffic and city simulation.

```bash
pnpm install
pnpm exec playwright install chromium   # once, for screenshot tests
pnpm dev                                # open http://localhost:5173
```

Drag to pan, scroll to zoom. **Space** pauses, **1–4** set speed (1×/2×/4×/8×), **L** toggles the lane graph.

See [CLAUDE.md](CLAUDE.md) for architecture, rules and commands.
